Project Background

왜 1인 미용실 전용 시스템인가?

실제 배우자가 운영하는 1인 미용실 현장의 페인포인트(Pain Point)를 분석하여 기획했습니다.

월 고정비 절감 및 경량화

대형 프랜차이즈 중심의 무겁고 비싼 월 구독형 CRM 대신, 1인 원장님에게 꼭 필요한 핵심 기능만 담아 유지 비용을 0원으로 절감합니다.

세분화된 시술 레시피 기록

고객별 모발 손상도, 염모제 배합 비율(예: 8-11 + 6%), 롯드 호수, 열처리 시간을 정밀 기록하고 시술 전/후 사진을 프라이빗하게 공유합니다.

외부 채널 연동 및 SaaS 확장

네이버 예약 동기화, D-1 안내 문자 자동 발송, 인스타그램 시술 영상 피드 연동을 지원하며 향후 타 1인 샵 대상 SaaS 모델을 지향합니다.

신규 고객 (1회)

예약 D-1 안내 메시지 자동화

네이버 예약 확정 데이터와 연동하여 방문 하루 전 오전 10시에 맞춤 안내톡을 발송합니다. 아래 입력값을 변경하면 우측 미리보기에 즉시 반영됩니다.

알림톡 미리보기 (D-1 발송)

고객 전용 프라이빗 뷰어

Supabase RLS(행 단위 보안)와 일회용 인증 링크를 활용하여, 접속한 고객은 오직 본인의 시술 전/후 사진 변화 기록만 열람할 수 있습니다.

인스타그램 시술 영상 연동

Instagram Graph API를 연동하여 미용실 공식 계정에 업로드된 최신 헤어 시술 릴스(Reels) 영상을 웹사이트에 자동 게시합니다.

네이버 예약 동기화

네이버 예약 확정 알림(Webhook/API)을 파싱하여 원장님 전용 대시보드 스케줄표에 빈틈없이 실시간 반영합니다.

System Architecture

무료 클라우드 기반 고효율 기술 스택

운영비 부담 없이 엔터프라이즈급 보안과 성능을 보장하는 아키텍처 설계입니다.

Frontend & Visualization

HTML5, CSS3, JavaScript(ES6+) 및 Chart.js를 활용하여 PC와 태블릿, 스마트폰 어디서나 쾌적한 반응형 대시보드를 구현합니다.

Supabase (DB & Storage)

PostgreSQL 관계형 DB로 고객·예약 스키마를 구축하고, 비공개 Storage 버킷과 RLS 정책으로 고객 시술 사진을 안전하게 보호합니다.

GitHub Pages & CI/CD

체계적인 Git 브랜치 및 커밋 컨벤션을 유지하며, GitHub Pages를 통해 포트폴리오와 기술 문서를 상시 배포합니다.
